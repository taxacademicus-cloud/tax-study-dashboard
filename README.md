# Tax Academics · Tax Study Lab (마인드맵 리디자인)

## 설치
1. 기존 GitHub 저장소 `taxacademicus-cloud/tax-study-dashboard`의 `index.html`, `style.css`, `app.js`를 이 폴더의 동명 파일로 교체합니다.
2. **기존 `firebase-config.js`는 삭제하거나 덮어쓰지 마세요.** 파일에 실제 Firebase 설정과 `OWNER_UID`가 있어야 합니다.
3. GitHub Pages 배포가 완료되면 강력 새로고침(Ctrl+Shift+R) 후 로그인합니다.

## 주요 기능
- 로그인 화면 문구 변경, 상단 TAX STUDY LAB, 왼쪽 메뉴 제거
- 과목별 전체 화면 마인드맵
- 대분류 > 중분류 > 소분류 > 주제 > 학습 내용
- 노드 추가/편집/삭제, 이미지 압축 첨부, JSON 백업
- Firestore `studyMindmaps/{본인UID}` 문서에 자동 저장

## 주의 사항
- 기존 앱의 데이터 스키마와 새 앱의 스키마는 다를 수 있습니다. 기존 데이터는 자동 이전되지 않습니다. 교체 전 기존 사이트에서 JSON 백업을 받아 두세요.
- 이미지 데이터는 압축 후 Firestore 문서에 포함됩니다. Firestore 문서 크기 제한(1MiB)이 있어 이미지가 많아지면 Firebase Storage 방식으로 변경해야 합니다.
- `firebase-config.js`는 기존 파일을 유지하고 `OWNER_UID`가 본인 계정과 일치해야 합니다.
- GitHub Pages는 공개 정적 사이트입니다. 학습 데이터의 접근 제어는 Firestore 보안 규칙이 담당합니다.
- 이 패키지는 기존 Firestore 보안 규칙을 변경하지 않습니다.


## 촬영용 뷰어 모드
- 로그인 후 상단의 `◩ 뷰어 모드` 버튼을 누르면 브라우저 전체 화면 마인드맵으로 전환됩니다.
- 상단바, 저장/설정/편집 입력, 대분류 추가 버튼, 사이드 편집기가 숨겨집니다.
- 홈에서 과목 노드를 클릭하면 해당 과목의 마인드맵으로 이동합니다.
- 과목 화면에서 노드를 클릭하면 기존 학습 내용을 읽기 전용으로 보여줍니다.
- **Esc 키**를 누르면 편집 화면으로 돌아옵니다. (전체 화면이 허용되지 않는 환경에서도 작동)
- 2차 시험 버튼은 홈 화면에서 제거했습니다.

## 촬영 뷰어 확대 기능 (이번 업데이트)
- 모든 마인드맵 노드는 **제목만** 표시하며, 대분류/중분류/소분류 등의 작은 라벨을 숨깁니다.
- 뷰어에서 노드를 누르면 우측 하단에 학습 내용 미리보기가 나타납니다.
- 우측 하단 미리보기를 누르면 중앙에 크게 확대됩니다. 이미지도 함께 확대 표시합니다.
- 확대 화면의 `✕ 닫기`, 바깥 영역 클릭, 또는 `Esc`로 확대 화면을 닫습니다. 확대 화면이 닫힌 뒤 `Esc`를 다시 누르면 뷰어에서 나갑니다.

## v3 사진 확대 동작
- 마인드맵 노드의 대분류/중분류/소분류 등 보조 글자는 표시하지 않고 제목만 표시합니다.
- 뷰어 모드에서 노드를 클릭한 뒤 **우측 하단 사진을 직접 클릭하면 사진만 중앙에 크게 확대**됩니다.
- 우측 하단 카드의 제목이나 글을 클릭하면 학습 내용과 사진을 함께 확대합니다.
- 중앙 확대 화면은 닫기 버튼, 배경 클릭, Esc로 닫습니다.
